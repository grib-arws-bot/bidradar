# BidRadar 브랜드 자산

> **마크** Target Lock — 조준경 형태의 동심원과 십자 틱, 그리고 중앙에서 벗어난 주황 블립 하나.
> 여러 신호 중 **우리에게 맞는 하나를 아직 조준하고 있는** 상태를 나타냅니다.
> **확정** 2026-09-01 · 의사결정 로그 8번

---

## 1. 파일 위치

```
brand/
├─ svg/
│  ├─ mark.svg                 기본 마크 (라이트 배경)      ← 웹·인쇄 원본
│  ├─ mark-dark.svg            어두운 배경용
│  ├─ mark-mono-black.svg      단색 검정 (팩스·워터마크·인쇄)
│  ├─ mark-mono-white.svg      단색 흰색
│  ├─ mark-32.svg              32px 최적화 (내부 링 제거)
│  ├─ favicon.svg              16px 최적화 (선 굵게)
│  └─ app-icon.svg             주황 배경 + 흰 마크, 512 기준
├─ favicon/  favicon.ico · favicon-16/32/48.png
├─ app/      apple-touch-icon-180.png · icon-192/512.png · site.webmanifest
├─ lockup/   lockup-light@1x/@2x.png · lockup-white@1x/@2x.png
├─ email/    mark-*-30/40 @1x/@2x · lockup-email-* @1x/@2x   ← PNG만 (SVG 차단)
├─ og/       og-image.png (1200×630)
├─ react/    Logo.tsx
└─ snippet/  head.html · email-header.html
```

## 2. 색

| 역할 | HEX | 용도 |
|---|---|---|
| Primary | `#DE5B21` | 블립, 워드마크 `Radar`, 앱 아이콘 배경, 강조선 |
| Primary Light | `#FF9E6B` | **어두운 배경 위에서만** 블립·강조 |
| Ink | `#161C24` | 십자 틱, 워드마크 `Bid`, 메일 헤더 바 |
| Grey 600 | `#637381` | 내부 링 |
| Grey 500 | `#919EAB` | 외부 링, 서브 텍스트 |

주황은 안전색채 계열에서 왔고, "감지·경계"라는 제품 성격을 나타냅니다.

**도메인 색은 브랜드 색이 아닙니다.** BidRadar는 특정 분야에 한정되지 않으므로, 화면에서 도메인(산업안전·스마트교육·기타)을 구분할 때 쓰는 색은 **도메인 레코드의 속성**으로 관리합니다. primary 주황을 특정 도메인에 고정하지 마십시오.

## 3. 타이포

- 워드마크: **DM Sans 700**, letter-spacing `-0.03em`
- 국문 병기 "입찰 레이더": DM Sans / Noto Sans KR 700, letter-spacing `0.16em`, 대문자 취급
- `Bid`는 잉크색, `Radar`는 주황 — **이 분리를 유지**합니다. 이름의 두 부분이 구분되어야 읽힙니다

## 4. 크기 규칙 ★

| 크기 | 사용할 파일 | 형태 |
|---|---|---|
| 48px 이상 | `mark.svg` | 외부 링 + 내부 링 + 십자 틱 + 블립 (완전형) |
| 32~47px | `mark-32.svg` | **내부 링 제거**, 선 두께 3.4 |
| 16~31px | `favicon.svg` | 내부 링 제거, 선 두께 5, 블립 확대 |

**마크를 24px 미만으로 축소해 쓰지 마십시오.** 완전형을 그대로 줄이면 내부 링과 블립이 뭉개집니다. 크기별로 다른 파일이 있는 이유입니다.

**최소 여백** 마크 한 변의 **1/4**을 사방에 확보합니다. 40px 마크라면 10px.

## 5. 웹 적용

`snippet/head.html`을 `frontend/index.html`의 `<head>`에 붙이고, 아래 파일을 `frontend/public/` **최상단**에 둡니다.

```
favicon.ico · favicon.svg · apple-touch-icon-180.png
icon-192.png · icon-512.png · site.webmanifest · og-image.png
```

화면 안에서는 `react/Logo.tsx`를 씁니다.

```tsx
<Logo />                        // 사이드바 헤더
<Logo variant="mark" size={32} />  // 축소 사이드바
<Logo tone="inverse" />         // 어두운 배경
<Logo size={30} showSub />      // "입찰 레이더" 병기
```

## 6. 메일 적용 ⚠️

**Gmail·Outlook은 SVG를 차단합니다.** 메일에는 반드시 PNG를 쓰고, 이미지를 절대 URL로 호스팅하십시오.

- `snippet/email-header.html` — 테이블 기반이라 Outlook에서도 깨지지 않습니다
- **어두운 바(`#161C24`) 위에 흰색 마크** 조합을 씁니다. 수신자가 다크 모드로 열어도 동일하게 보이는 유일하게 안전한 방식입니다
- 흰 배경에 검정 마크를 얹으면 다크 모드에서 마크가 배경에 묻힙니다 — 하지 마십시오
- `@2x`를 `src`에 넣고 `width`/`height`는 `@1x` 값으로 지정해야 고해상도 화면에서 선명합니다
- `alt="BidRadar"`를 반드시 넣으십시오. 이미지 차단이 기본인 클라이언트가 많습니다

## 7. 하지 말 것

- 마크를 회전하거나 기울이지 않습니다 — 십자 틱이 수직·수평이어야 조준경으로 읽힙니다
- 블립 위치(우상단)를 옮기지 않습니다. 정중앙에 두면 "이미 맞춘" 의미가 되어 제품과 어긋납니다
- 워드마크를 다른 서체로 다시 조판하지 않습니다. 제공된 락업 PNG나 `Logo.tsx`를 씁니다
- 마크에 그림자·외곽선·그라디언트를 덧대지 않습니다
- 주황을 배경으로 쓸 때 마크는 **흰색 단색**만 씁니다 (`app-icon.svg` 참조)
- 로고를 사진 위에 직접 올리지 않습니다. 단색 판을 깔고 그 위에 놓습니다
