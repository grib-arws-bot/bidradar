# advisory/ — 아키텍트 전용 폴더

시스템 아키텍트(Cowork 세션)가 쓰는 폴더입니다. **Claude Code는 읽기만 하고 쓰지 않습니다.**

## 구조

| 폴더 | 내용 |
|---|---|
| `adr/` | 아키텍처 결정 제안 — `NNN-제목.md` |
| `review/` | 적대적 검토·정합성 감사 결과 — `YYYY-MM-DD-대상.md` |
| `research/` | 외부 조사 (API·법령·이용약관·경쟁) — `YYYY-MM-DD-주제.md` |
| `INBOX.md` | Claude Code에 넘길 실행 항목 대기열 |

## 규칙

**1. 여기 있는 것은 제안이지 확정이 아닙니다.**
Jeffrey가 승인하고 Claude Code가 반영해야 효력이 생깁니다. `advisory/`에 문서가 있다는 것만으로 코드나 `docs/`가 바뀌지 않습니다.

**2. 양쪽이 같은 파일을 쓰지 않습니다.**
`docs/의사결정_로그.md` 등재는 **Claude Code만** 합니다. 아키텍트는 `adr/`에 개별 파일로 쓰고, 승인된 것을 Claude Code가 로그에 옮깁니다.
→ 2026-09-01 로그 유실 사고(Cowork가 로그를 전체 덮어써 Claude Code가 추가한 4개 항목이 작업트리에서 사라짐)의 재발 방지책입니다.

**3. 기존 파일은 추가·수정만 하고 전체 덮어쓰기를 하지 않습니다.**

**4. 조사 문서에는 날짜를 붙입니다.**
API 스펙·robots.txt·이용약관은 바뀝니다. 언제 확인한 것인지가 문서의 신뢰 구간입니다.

**5. 확인하지 못한 것은 "미확인"으로 남깁니다.**
추정을 사실처럼 적지 않습니다. 각 문서 끝에 "조사 한계" 절을 둡니다.
