# IRIS 사업공고·공모예고 수집 경로 조사

> **질문** 범부처통합연구지원시스템(IRIS)에서 사업공고·공모예고를 OpenAPI로 수집할 수 있는가? 상업적 이용이 가능한가?
> **조사일** 2026-09-01 · 조사자 아키텍트(Cowork)
> **상태** 조사 완료 · **미결 1건**(6절)

**개정 이력**

| 판 | 내용 |
|---|---|
| v1 | 웹 자동조회 기반 1차 조사 |
| **v2** | **브라우저 직접 조사로 갱신.** ① `ancmPrg=ancmPre` 판정 **정정** ② 공고예정 페이지 실체 확인 ③ **이용약관 확인 완료** ④ 기술분야 분류체계 발견 |

## 0. 결론

**IRIS 전용 OpenAPI는 없습니다.** 공식 API·RSS 모두 제공하지 않습니다.

다만 **수집 조건은 예상보다 좋습니다.** 접수예정 목록이 별도 GET URL로 열려 있고, robots.txt가 막지 않으며, **상업적 이용을 금지하는 약관 조항이 존재하지 않습니다.**

| 경로 | 범부처 | 접수예정(예고) | 마감일 | 수집 방식 | 리스크 |
|---|---|---|---|---|---|
| **IRIS 직접** | ✅ 34개 부처 | ✅ **유일** | ✅ | HTML(서버렌더링) | **낮음** — 6절 참조 |
| **과기정통부 API** `15074634` | ❌ 과기정통부만 | ❌ | ❌ **없음** | OpenAPI | 없음 |
| **NTIS** | ✅ | 미확인 | 미확인 | ❌ robots 전면차단 | 수집 불가 |

## 1. ⚠️ v1 정정 — 공고예정은 쿼리 파라미터가 아니라 별도 URL

v1에서 `ancmPrg=ancmPre` 를 공고예정 필터로 추정했으나 **틀렸습니다.**

```
❌ /contents/retrieveBsnsAncmListView.do?ancmPrg=ancmPre
   → 파라미터가 무시되고 "공고중" 목록이 그대로 나옴 (직접 확인)
```

실제 구조는 이렇습니다. 탭의 DOM을 읽어 확인했습니다.

| 탭 | 실제 동작 | 수집 난이도 |
|---|---|---|
| **접수예정** | `<a href="retrieveBsnsAncmBtinSituListView.do">` — **별도 페이지, GET** | ✅ 쉬움 |
| 접수중 | `f_bsnsAncmListForm_search('ancmPrg')` — **POST 폼** | ⚠️ 폼 전송 필요 |
| 마감 | `f_bsnsAncmListForm_search('ancmEnd')` — **POST 폼** | ⚠️ 폼 전송 필요 |

**BidRadar에 가장 중요한 접수예정이 가장 쉬운 경로**라는 점이 다행입니다. 단순 GET으로 접근됩니다.

## 2. ★ 접수예정 페이지 — 실제 수집 대상

```
https://www.iris.go.kr/contents/retrieveBsnsAncmBtinSituListView.do
```

v1에서 "현황 페이지"로만 적었으나, 실제로는 **필터가 훨씬 풍부한 본 수집 대상**입니다. HTTP 200, 조사 시점 **전체 15건 / 2페이지**.

**탭** 접수예정 · 접수중 · 마감 *(목록 페이지의 "공고예정" 명칭과 다름 — 여기서는 "접수예정")*

**필터 3축**

| 축 | 개수 | 내용 |
|---|---|---|
| 소관부처 | **34** | 범부처 · 과기정통부 · 산업통상부 · 중기부 · 국토부 · 교육부 · **고용노동부** · **경찰청** · **소방청** · 방위사업청 · 조달청 · 우주항공청 등 |
| 전문기관 | **42** | KISTEP · NRF · KEIT · IITP · KIAT · KETEP · KHIDI · **한국산업안전보건공단(KOSHA)** · 한국인터넷진흥원 · 한국콘텐츠진흥원 등 |
| **기술분야** | **22** | 수학 · 물리학 · 화학 · 지구과학 · 생명과학 · 농림수산식품 · 보건의료 · **기계** · 재료 · 화공 · **전기/전자** · **정보/통신** · 에너지/자원 · 원자력 · **환경** · **건설/교통** · 뇌과학 · 인지/감성과학 · 과학기술과 인문사회 · 문화예술체육학 · 인문학 · 사회과학 |

### 기술분야 22개가 뜻밖의 소득입니다

설계안 05절에서 고객 관심주제 분류체계를 찾다가 **"국가과학기술표준분류는 소분류 2,800개라 고객이 훑을 규모가 아니다"**라고 판정했습니다.

**IRIS의 기술분야 22개는 그 문제의 답이 될 수 있습니다.** 정부 공식 분류이면서 고객이 한 화면에서 고를 수 있는 크기이고, 수집 시점에 이미 부여되어 있어 별도 분류 작업이 필요 없습니다. S7 관심주제 프리셋의 후보로 검토할 가치가 있습니다.

### 산업안전 R&D가 실제로 들어옵니다

소관부처에 **고용노동부·경찰청·소방청**, 전문기관에 **한국산업안전보건공단(KOSHA)**이 있습니다. IRIS가 R&D 전용이라 BidRadar 핵심 도메인과 멀 것이라는 v1 판단(설계안 Tier 5의 "구매성 입찰 비중이 크므로 보완재")은 유효하지만, **산업안전 분야 R&D 채널로서는 직접적**입니다.

## 3. ★ 이용약관 확인 — 상업적 이용 금지 조항 없음

**v1의 최대 미결이었고, 이번에 해소했습니다.**

브라우저로 푸터와 관련 페이지를 직접 확인한 결과입니다.

| 확인 항목 | 결과 |
|---|---|
| 푸터 링크 전체 | **개인정보처리방침 · 공지사항 · 고객센터 · 이용안내** — 4개가 전부 |
| **이용약관 페이지** | ❌ **존재하지 않음** (공개 영역에 없음) |
| **저작권 정책** | ❌ **존재하지 않음** |
| 푸터 저작권 문구 | ❌ 없음 — `Copyright` / `All rights reserved` 문자열 자체가 페이지에 없음 |
| **공공누리(KOGL) 표시** | ❌ 없음 — `공공누리`/`KOGL` 문자열·이미지 모두 없음 |
| 이용안내 내용 | 브라우저 권장 환경 · 글자크기 · 웹접근성 · 메뉴 안내뿐. **이용조건·저작권 조항 전무** |

### 판단

**KIAT 제19조②(정보 가공·판매 등 상업적 이용 금지)나 S2B 제31조②(복제·송신·배포 금지) 같은 명시적 금지 조항이 IRIS에는 없습니다.**

다만 정확히 말하면 이렇습니다.

- ✅ **금지 조항이 확인되지 않음** — 두 전례와 달리 걸리는 조항이 없음
- ⚠️ **"금지 없음"이 "허용"은 아님** — 공공누리 표시도 없어 이용조건이 **명시되지 않은 상태**
- ℹ️ 회원가입 시 동의하는 약관은 별도로 있을 수 있으나(비회원 공개 영역에는 없음), **수집은 비로그인 공개 페이지 대상**이므로 해당 없음

### 권고 — 저위험이나 무위험은 아님

**원문 전재가 아니라 "요약 + 원문 링크" 방식이면 위험이 낮습니다.** 근거는 셋입니다.

1. robots.txt가 사업공고 경로를 허용
2. 명시적 금지 조항 부재
3. 대상 정보의 성격이 **공공 R&D 사업공고** — 널리 알려지는 것이 발행 목적에 부합

유료 뉴스레터라도 이 방식이면 합리적입니다. 다만 **원문을 통째로 옮겨 싣는 것은 권하지 않습니다** — 이용조건이 명시되지 않은 상태에서는 전재가 가장 다투기 쉬운 지점입니다.

운영기관은 **한국과학기술기획평가원**(충북 음성군 맹동면 원중로 1339 / 042-862-1500)입니다. 서면 질의로 확답을 받아두면 가장 안전하지만, 착수를 막을 정도의 위험은 아니라고 봅니다.

## 4. 과기정통부_사업공고 API (data.go.kr `15074634`)

```
https://apis.data.go.kr/1721000/msitannouncementinfo/businessAnnouncMentList
```

| | |
|---|---|
| 범위 | **과기정통부 자체 공고만.** 범부처 아님 |
| 필수 항목 | 공고제목(`subject`) · 상세URL(`viewUrl`) · 게시일(`pressDt`) |
| 선택 항목 | 담당부서 · 담당자 · 연락처 · 첨부파일(`fileName`/`fileUrl`) |
| 갱신 | 1일 1회 |
| 트래픽 | 개발계정 10,000건/일 · 초당 제한 있음(에러코드 23) |

### ⚠️ 마감일이 없습니다

`close_dt` 에 해당하는 항목이 없어 **D-day · 마감임박 필터 · 시급도 계수 · 일정 역산**이 전부 불가능합니다. INBOX #1 참조.

**보완재이지 대체재가 아닙니다.** 다만 리스크 0에 즉시 붙습니다.

## 5. NTIS — 수집 불가

`ntis.go.kr` 은 **robots.txt로 차단**되어 자동 조회가 거부되었습니다. Open API 안내 페이지의 존재는 확인했으나 내용은 읽지 못했습니다.

data.go.kr의 KISTI/NTIS 계열 API는 전부 **사후 데이터**입니다.

| 데이터셋 | 내용 | 적합성 |
|---|---|---|
| `15077315` 국가R&D 과제검색 | 선정된 **과제** | ❌ 사후 |
| `15102622` 연구보고서 검색 | 완료 **보고서** | ❌ 사후 |
| `15138962` 수행기관 R&D현황 | 기관별 수행 현황 | ❌ 사후 |

**권고: NTIS 포기.** IRIS가 같은 공고를 대부분 담고 있습니다.

## 6. 남은 미결 1건

### NTIS Open API의 실제 목록 — 확인 불가

robots 차단으로 조사하지 못했습니다. 거기에 공고 API가 있다면 IRIS 스크레이핑보다 나은 선택지가 되므로, **Jeffrey가 직접 열어볼 가치**는 있습니다. 다만 IRIS 경로가 열린 이상 급하지 않습니다.

> v1의 미결 ①(이용약관)과 ③(`ancmPre` 동작)은 이번 조사로 **해소**되었습니다.

## 8. 조사 한계

- IRIS 조사는 **브라우저 직접 접근**으로 수행했습니다(v1은 웹 자동조회만). robots.txt·DOM·푸터·이용안내를 실제로 읽었습니다
- **과기정통부 API는 실호출하지 않았습니다.** 응답 형태·필드는 data.go.kr 문서 기재 내용이며 미검증입니다
- NTIS는 robots 차단으로 **전혀 확인하지 못했습니다**
- 건수(접수예정 15건 / 접수중 63건)는 조사 시점 값입니다
- robots.txt·약관·페이지 구조는 예고 없이 바뀝니다. **2026-09-01 기준**입니다
