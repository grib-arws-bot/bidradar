**출처** `research/2026-09-01-경쟁서비스-및-약관제약-해결방안.md` 3-5절 ①
**결정** 2026-09-01 Jeffrey 확정

공고 데이터에 담당자 **이름과 연락처**가 포함됩니다. 과기정통부 API는 `managerName` · `managerTel`, 나라장터 공고에도 담당자 정보가 있습니다.

**공개된 정보라도 화면에 표시하는 것과 외부 고객에게 메일로 발송하는 것은 다릅니다.** 목적 외 이용·제3자 제공 쟁점이 생깁니다.

### 해야 할 것

```
수집 단계   담당자 이름·연락처·이메일을 매핑 대상에서 제외한다
            (수집은 하되 버리는 게 아니라, 애초에 저장하지 않는다)
저장 단계   notice / raw_payload / analysis 어디에도 남기지 않는다
            raw_payload 는 원본 보존이 원칙이나, 개인정보는 예외로 마스킹한다
발송 단계   뉴스레터·PublicReportPage·리포트 내보내기에 노출 금지
유지        deptName 같은 조직 정보는 유지 — 개인 식별이 아님
```

### 이미 수집된 데이터가 있으면

`notice` · `raw_payload` 에 담당자 정보가 들어간 레코드가 있는지 확인하고, **있으면 마스킹 마이그레이션을 작성**해라. 시드 데이터도 확인할 것.

### 왜 지금인가

나중에 빼려면 **이미 발송된 메일 이력까지 문제**가 됩니다. 지금이 가장 쌉니다.

**왜 이 URL인가** — 사업공고 목록(`retrieveBsnsAncmListView.do`)의 "접수예정" 탭은 **별도 페이지 링크**다. 같은 페이지에 `?ancmPrg=ancmPre` 를 붙이는 것은 **동작하지 않는다**(파라미터 무시, 접수중 목록이 그대로 나옴 — 직접 확인).

**목록 항목** 부처/기관명 · 공고제목 · 세부사업명 · 통합공고명 · 내역사업명 · 사업공고명 · 접수유형 · 접수기간(`YYYY/MM/DD~YYYY/MM/DD`)

**상세 URL**
```
/contents/retrieveBsnsAncmView.do?ancmId=NNNNNN&bsnsYyDetail=YYYY&sorgnBsnsCd=SNNNNNN&bsnsAncmSn=N
```

**접수중·마감 탭은 이번 범위 아님** — POST 폼 필요(`f_bsnsAncmListForm_search('ancmPrg'|'ancmEnd')`).

## #5 · 대기 ★ · 소스 법적 등급(`legal_tier`) 도입

**출처** `research/2026-09-01-경쟁서비스-및-약관제약-해결방안.md` 3-1·3-2절
**중요도 최상 — 유료 서비스의 법적 방어선입니다**

지금 소스 레지스트리에는 robots.txt 확인과 약관 체크박스가 있으나 **관리자가 체크박스만 누르면 통과됩니다.** 등급을 데이터로 만들고 **코드가 강제**해야 합니다.

### 스키마 추가 (`source` 테이블)

```
legal_tier          'A' | 'B' | 'C'   (필수)
license_note        text              근거 문구 (예: 이용허락범위 "제한 없음")
license_evidence_url text             근거 URL
legal_verified_at   timestamp         최종 확인 시각
robots_hash         text              robots.txt 해시 (변경 감지용)
```

### 등급별 강제 동작

| 등급 | 조건 | 시스템 동작 |
|---|---|---|
| **A** | data.go.kr 등 **이용허락범위 "제한 없음"** | 원문 전재 허용 · **출처표시 자동 삽입** |
| **B** | robots 허용 + 명시적 금지조항 없음 | **원문 본문 저장 차단(요약만)** · 아웃링크 필수 · **최소 필드만**(제목·기관·기간·링크) · 수집 간격 하한 강제 |
| **C** | robots 차단 또는 명시적 금지조항 | **활성화 자체를 거부.** 관리자가 체크박스로도 못 켠다 |

### 현재 소스 등급 (조사 결과)

```
A : 나라장터 API 전체 · 과기정통부 사업공고 · K-water · 도로공사 등 data.go.kr 계열
B : IRIS
C : NTIS(robots 차단) · S2B(약관 제31조②) · KIAT(약관 제19조②)
    SEMAS(저작권정책) · NRF · KETEP · IPET · IITP(robots 차단)
```

### 왜 이렇게까지 하는가

대법원 2022. 5. 12. 선고 2021도1533은 크롤링 형사책임을 무죄로 봤지만, **같은 사건의 민사 1심은 부정경쟁방지법 위반을 인정**했습니다. 형사 안전이 민사 안전이 아닙니다. 판례가 유죄 요소로 든 것이 **"정체 미명시 · robots 무시 · 상당량 수집"**이므로, 그 반대를 시스템이 강제하면 방어선이 됩니다.

## #6 · 대기 · 소스 준법 상태 분기 재검증

**출처** 같은 문서 3-3절

robots.txt와 약관은 **예고 없이 바뀝니다.** 어제까지 적법하던 수집이 오늘 위법이 될 수 있습니다.

- **분기 1회 자동 재확인** — robots.txt 해시 비교, 약관 페이지 신설 여부
- **변경 감지 시 해당 소스 자동 비활성화 + 관리자 알림**
- 결과를 `legal_verified_at` · `robots_hash` 에 기록
- 소스 관리 화면(S5)에 **"마지막 준법 확인일"** 컬럼 추가. 90일 경과 시 경고 배지

## #7 · 대기 · 출처표시 자동 삽입

**출처** 같은 문서 2-1절

공공데이터포털 이용정책상 **제0유형 외 전 유형에서 출처표시가 의무**입니다. A등급 소스의 데이터를 뉴스레터·리포트·화면에 쓸 때 출처가 자동으로 붙어야 합니다.

- `source` 에 `attribution_text` 필드 (예: `출처: 조달청 나라장터 입찰공고정보서비스`)
- 뉴스레터·PublicReportPage·S8 리포트 내보내기(DOCX/PDF)에 자동 삽입
- **사람이 빠뜨릴 수 있는 자리에 두지 말 것** — 템플릿 레벨에서 강제
